# 胡桃游戏性能面板免安装预览 v3

1. 把 ZIP 完整解压到新文件夹。右键 `Start-PerformancePanel-Preview.cmd`，选择「以管理员身份运行」。
2. 在「启动游戏 → 游戏选项」开启「游戏性能面板」，再从预览版启动原神。面板使用自己的开关。
3. 窗口模式下可以拖动面板位置。游戏铺满屏幕时，鼠标点击会穿过面板，避免切走游戏焦点。切回窗口模式后可以继续拖动或关闭面板。
4. 游戏最小化时面板会隐藏，回到游戏后自动显示。游戏退出后，可在「游戏选项」关闭开关，控制下次启动游戏时是否自动显示。

展开「游戏性能面板」即可设置界面缩放、背景颜色和不透明度。设置会保存，运行中的面板也会更新。

FPS 统计游戏向显卡提交画面的速率。「1% Low」取最近约五秒内最慢 1% 帧间隔的平均值后折算为 FPS。至少采到 100 个间隔才显示这个数。

CPU 占用率为整机指标。CPU 温度来自受支持的华硕 WMI 传感器，显卡指标来自 NVIDIA 驱动。不可用的传感器显示横线。

启动脚本沿用上一版的预览配置目录 `%LOCALAPPDATA%\SnapHutao-PerformancePanel-Preview`。采集使用随包的 PresentMon 2.6.0，目录内附 MIT 许可。
