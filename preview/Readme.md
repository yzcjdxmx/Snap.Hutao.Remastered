# 胡桃实测 FPS 免安装预览版

1. 把 ZIP 完整解压到一个新文件夹。右键 `Start-RealtimeFPS-Preview.cmd`，选择「以管理员身份运行」。
2. 在预览版内指定原神的安装位置，在「启动游戏」中启用胡桃悬浮窗，然后从预览版启动原神。
3. 回到悬浮窗，点「实测 FPS」开始采集。正常情况下约一至两秒出现数值。再点一次即可关闭采集。

「实测 FPS」显示游戏进程每秒提交的帧数。胡桃原有的 FPS 控件仍显示设置的目标值。建议在无边框窗口模式先看读数，再测试切换焦点和关闭开关。独占全屏下是否显示悬浮窗取决于实际环境。

启动脚本使用 `%LOCALAPPDATA%\SnapHutao-RealtimeFPS-Preview` 保存预览版的设置。请始终用启动脚本打开预览版。

采集使用预览包内的 PresentMon 2.6.0。目录内附 MIT 许可。
