# 胡桃游戏性能面板免安装预览

1. 把 ZIP 完整解压到新文件夹。右键 `Start-PerformancePanel-Preview.cmd`，选择「以管理员身份运行」。
2. 在预览版指定原神安装位置，在「启动游戏 → 游戏选项」开启悬浮窗，从预览版启动游戏。
3. 游戏以窗口模式运行时，点胡桃浮窗上的「性能面板」。可以拖动小面板本身，上方胡桃工具条的位置会保持原样。点面板右侧的关闭按钮可停止采集。
4. 让原神保持前台，切到独占全屏，确认小面板是否自动回到游戏画面上方。再切回窗口模式，确认仍能显示。

FPS 统计游戏向显卡提交画面的速率。「1% Low」取最近约五秒内最慢 1% 帧间隔的平均值后折算为 FPS。至少采到 100 个间隔才显示这个数。

启动脚本把预览设置存到 `%LOCALAPPDATA%\SnapHutao-PerformancePanel-Preview`。采集使用随包的 PresentMon 2.6.0，目录内附 MIT 许可。
